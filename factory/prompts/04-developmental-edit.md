# Developmental edit pass

Run on a finished draft, before the build. The substance gate catches padding,
repetition, and abstraction. It cannot catch a chapter that is well written and
pointless. That is this pass.

---

For each unit, answer in one line each:

1. **What does this unit do that no other unit does?** If you cannot answer,
   it is a candidate for merging.
2. **What is the reader able to do afterward?** Quote the sentence where the
   book actually says it. If you cannot quote it, it is not in there.
3. **Where is the evidence?** For any claim about how people, money, bodies, or
   institutions behave: first-hand experience, a named source, or cut it.
4. **Where does it stop being Chris?** Mark any passage that could have been
   written by a man who has never worked a night shift. Those are the passages
   that make the whole book feel generic.
5. **What is the weakest paragraph?** Name it. Every unit has one.

Then, across the book:

- Which two units are secretly the same argument in different clothes?
- Which unit is carrying the book, and does it come early enough that a reader
  sampling the first pages reaches it?
- Where does the book promise something in the front matter that it never pays?
- Is there a stretch of three units where nothing new is introduced?

Return a cut list and a rewrite list, ordered by how much each one improves the
book. Do not return praise.
